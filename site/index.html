Alerts

A sound when an agent waits, and an optional notification on your phone.

Checks

Name a command, such as your tests. Maitty runs it after every turn, so a broken turn reads failed, not done.

# config.toml
[[check]]
project = "/home/me/code/my-app"
name    = "test"
command = "cargo test"
