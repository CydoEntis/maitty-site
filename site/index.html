Know who needs you.

Every session shows whether its agent is working, needs you, has finished or is idle, read from the agent's own hooks where it has them. When one waits, Maitty plays a sound and can send an alert to your phone.

⠴ working
Busy on its turn.
● needs you
A question or approval is waiting.
● done
The turn finished and its checks passed.
○ idle
Nothing running.

Close it, come back.

A background service owns every session. Close the window and your agents keep running; run maitty to come back. After a crash or a reboot, Maitty reopens them in the right folders and resumes their conversations.

A branch per agent, review in place.

Each new agent gets its own Git worktree, so no two edit the same files. Files, Changes and Branch open in a side panel beside your panes: review each file's diff, then commit, merge or open a pull request without leaving.

Inbox, alerts and checks.

Inbox

Questions, failed checks and finished work collect in one place, most urgent first.

Alerts

A sound when an agent waits, and an optional notification on your phone.

Checks

Name a command, such as your tests. Maitty runs it after every turn, so a broken turn reads failed, not done.

# config.toml
[[check]]
name    = "test"
command = "cargo test"

Agents that work together.

Everything works from any shell, including from an agent running inside Maitty. Through MCP, agents can list, read, message and start other sessions, within limits you set.

$ maitty worktree feat/login -- codex
# a new branch in its own worktree, with codex
$ maitty send -p 3 "run the tests"
# message session 3
$ maitty handoff 3 --to claude
# hand its task to another agent
$ maitty ls --json
# every session and its status
